# 🎨 Color Detector Robot

This is a simple robot that detects specific colors using the TCS3200 sensor and reacts accordingly. It also uses ultrasonic sensors for obstacle avoidance and is powered by DC motors controlled via the L298 driver.
The robot was programmed in C. See `color_detector.c` for the complete code.

## 🧰 Components Used
- TCS3200 color sensor
- 3x Ultrasonic sensors (HC-SR04)
- Arduino Mega 2560 Rev3
- 4 DC motors with 4 wheels
- L298 motor driver
- Power supply
- 3x Lithium batteries

## ⚙️ Features
- Detects and reacts to colors using the TCS3200
- Avoids obstacles using 3 ultrasonic sensors
- Controlled by an Arduino Mega 2560
- Mobile robot with 4 motorized wheels
